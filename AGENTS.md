# Feature workflow

When you receive a feature request, use these skills in this exact sequence:

1. `/groom` - clarify requirements
2. `/planner` - create implementation plan
3. `/diagram` - draw a diagram of the implementation plan
4. `/implementer` - implement step by step
5. `/validator` - verify and report

Do not skip any step. When completing the each step, ask the user if they want to continue to the next step.
